# C - malloc, free

This project covers automatic and dynamic memory allocation in C,
using malloc and free, and managing dynamically allocated memory.

## Tasks

| File | Description |
| --- | --- |
| 0-create_array.c | Creates and initializes an array of characters |
| 1-strdup.c | Duplicates a string into newly allocated memory |
| 2-str_concat.c | Concatenates two strings into newly allocated memory |
| 3-alloc_grid.c | Allocates and initializes a two-dimensional integer array |
| 4-free_grid.c | Frees a dynamically allocated two-dimensional array |
| main.h | Function prototypes |
