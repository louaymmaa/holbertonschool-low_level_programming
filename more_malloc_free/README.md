# C - More malloc, free

This project covers dynamic memory allocation in C, process
termination using exit, and memory initialization using malloc.

## Files

| File | Description |
| --- | --- |
| 0-malloc_checked.c | Allocates memory and exits on failure. |
| 1-string_nconcat.c | Concatenates two strings up to a specified limit. |
| 2-calloc.c | Allocates memory and initializes it to zero. |
| 3-array_range.c | Creates an array of consecutive integers. |
| main.h | Function prototypes. |

## Requirements

- Ubuntu 20.04 LTS
- GCC with -Wall -Werror -Wextra -pedantic -std=gnu89
- Betty coding style
- No global variables
- Only malloc, free and exit are allowed standard library functions.
